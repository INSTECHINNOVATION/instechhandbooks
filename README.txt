INSTECH GLOBAL SCHOOL — ACADEMIC PARENT HANDBOOK
================================================

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox or Safari).
3. The handbook works as a standalone static website. No build tools or server are required.
4. Use Previous / Next, Contents, keyboard arrow keys, or swipe on a touchscreen to turn pages.

FILES
- index.html: handbook content and structure
- style.css: responsive design and layout
- script.js: page navigation and contents panel
- assets/: original SVG illustrations used inside the handbook

NOTES
- Programme fees are transcribed from the supplied image.
- The supplied fee guide's class-duration wording is ambiguous, so the handbook advises parents to confirm the final timetable and lesson duration with the school.
- Contact information follows the supplied programme image.
